# Neuro Trace V2.3

面向手机的神经纤维追踪原型。根目录提供可交互前端，api 与 lib 提供 Vercel Node 服务，db 下保留 PostgreSQL 迁移脚本。[正式站](https://neurotrace-ui-demo.vercel.app)

## 版本回看

桌面端在右侧「交互状态」上方选择版本。窄屏设备在游戏外的「版本回看」栏操作。每个版本都有固定地址，例如 `/history/2.2/`。使用 `/compare/?a=2.2&b=2.3`，即可在同一页比较两版研究现场。比较页的两侧可以各自换版和操作，复制地址即可复现这组比较。

早期 V0.1–V0.3 是设计评审原型，V0.4 开始有可玩的连线任务。历史回看保留原先的页面与资源，每一版的试玩进度各自保存。近几版的公开榜单读取归档时取得的公开数据；历史回看不展示私人信箱或执行正式账户操作。正式登录和积分登记请从首页进入。

### 后续如何发布

1. 在根目录更新游戏代码、素材和 `release.json` 中的版本号，例如 `2.4.0`。
2. 执行 `python3 tools/freeze_release.py freeze 2.4 --label "版本短标题" --summary "本版可观察的具体变化"`。它只创建新编号。已有编号会报错，历史目录的文件不会被覆盖。
3. 运行 `python3 tools/freeze_release.py verify`、`python3 tests/verify_versions23.py` 和 `node --test tests/*.cjs`。发布源文件由 `python3 tools/public_manifest.py` 生成。此清单包含历史目录，并在生成前核验最新归档与当前游戏前端一致。
4. 把清单及对应字节部署到原 Vercel 项目，再检查首页、最新固定版本地址和与上一版的对照链接。

每份 `history/<版本>/manifest.json` 记录文件校验值及来源。重复部署同一旧编号时，本轮选择该编号最后一次成功上线的前端。V1.7–V1.9 的公开回看去除了旧客户端中内置的面向个人的信件内容。原部署缺少的 V1.5 私人授权音轨未收录。各时期自身的标题、图案和界面留在原版中，评审栏显示核实过的版本号。

## 玩法与保存

- 「文明」包括世界版图、任务对照和识别手册。底图源自 Allen CCFv3 标注体积。目前八个样本均为教学几何，真实脑区坐标及科研贡献有待实验数据配准和审核。[脑图数据与使用条件](docs/ATLAS19.md)
- 「回声档案」从北岭站交接第一张底片开始。C-101 / V-426 / T-315 对应《乡村教师》《三体》《带上她的眼睛》的文学线索，依次练习主干、弱信号和投影交叉。每份首次校验发放 600、800、1000 积分，合成「外景 01」整章。
- 外景 02《镜湖双城电台》、03《退潮后的来信》、04《山脊校片室》各有一份独立三维训练底片。三章开放选取，分别训练深度分层、采样边界及分叉判断，通关后收藏对应的笔记。
- 「任务手册」包括六份有参考答案的剧情训练及两项可任选顺序的观察委托。H-204 与 D-537 的两份报告合起来完成「双样本观察委托」。登记候选或证据不足均为有效的教学记录。玩家提交的连接不自动获得科研贡献。
- 所有玩家共用公开剧情。两位正式开发者在完成「外景 01」或「双样本观察委托」后，分别在对方的私信会话里收到一封自动信。服务端按验证过的收件人 ID 和完成里程碑发送正文，已读状态保存在数据库；手写回复仍为本机草稿。
- 群星提供积分榜和表现榜，均可选周、月、总三个范围。积分总榜显示余额，周、月按上海自然周、月统计账本净增，期初积分不计入周、月。表现按所选范围内各个不同训练样本的最佳分取平均，同时展示满分通关数和已测数。旧版成绩没有日期，仅进入总榜。009 迁移后，新的正式提交会自动计入对应周期。
- 研究页默认使用「金牛取景」。V2.3 的金牛座宽、高均为 V2.2 的 80%，连线不透明度降低约 13%，取景框最低仍高于地平线约 0.75°。右上「调节」可切到星座全貌或武汉广角。使用 `python tools/render_sky.py PHOTO_DIR OUTPUT_DIR --study` 和三张原始照片可重建本版画面，省略 `--study` 可重建两个观测方向。`python tools/sky_check.py` 可复核方位和时间。[观测条件与摄影来源](docs/TAURUS_SKY.html)

## 评分与复核

每次校验先将无向连线去重。若正确、多连、漏连条数分别为 TP、FP、FN，得分取 200 × TP / (2 × TP + FP + FN) 的四舍五入整数。全对才能通关。首次成绩记录首次提交，个人最佳允许复练，两个均分均按已测的不同样本计算。没有参考答案的观察报告进入待复核状态。

完成首章，且至少四份不同训练样本的个人最佳 ≥85，可打开任务手册里的「双视角复核席」。两视图按原报告绘制，玩家可保留候选、建议重查或标记证据不足并说明依据。该门槛为本次游戏原型设定，真实科研派单需要独立校准样本、实验数据及课题组复核。

正式玩家的成绩由 `/api/practice` 依据同一套三维几何和答案校验。账户同时记录首次、当前和最佳分。管理控制台的「训练表现」可对照达标样本数、首次与最佳均分、积分余额。匿名试玩只在本机计分。复核意见保存在本机当前账号下。首章沿用正式积分账本，新三章奖励独立藏品。

外景 02–04 的每一章都有独立的外景封面和任务近物插画。这六张 WebP 以第一章的观测站和底片图为原画参考重新绘制。

## 登录

首次打开时可选择四七、小王或本机试玩。两位正式账号沿用原有账号 ID、角色和积分。第一次在一台浏览器使用四位密码，先在对应的私人授权卡中打开正式站，再输入该账号的约定密码。之后可以从原站选择同一账号和输入四位密码登录。授权按账号区分，有效期 180 天，登录会话有效期 4 小时。私人授权入口使用一次后失效。连续输错五次会暂停该凭证 15 分钟。


[开发者账号首次激活](docs/DEVELOPER_ACCOUNTS.md) · [QQ 与微信的申请和联调](docs/SOCIAL_LOGIN.md)

初次使用社交渠道的开发者应先用已有 Neuro Trace 账号登录，绑定自己的微信或 QQ，之后可经该渠道回到相同的账号。未经绑定的外部身份以普通玩家权限加入。

## 运行与验证

前端本地试玩可从项目目录运行 `python -m http.server 8000` 后打开浏览器。服务端需 Vercel Functions 或等价的 Node 开发环境，已有受限数据库角色的连接由服务端变量 `NEUROTRACE_DATABASE_URL` 提供。单独静态托管支持离线试玩，账号功能需要服务端。

使用 `node --test tests/*.cjs` 验证身份、视图、连线、账号隔离与任务奖励。SQL 集成测试在隔离的预览分支运行。005 为网站 OAuth 绑定，006 为期初积分、观察报告、里程碑和已读状态。005 及采用本版积分单位的 006 已于 2026-11-06 在正式库应用。007 为独立训练评分表及受限查询函数，已于 2026-11-07 在正式库应用。初始入账不计入周榜/月榜。项目没有内置应用密钥与开发者登录凭据。
