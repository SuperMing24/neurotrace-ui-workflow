# NeuroTrace 当前界面与交互说明

2026-11-07 根据已恢复的 V2.3 实现和本轮要求整理。这是当前实现说明，不是原始需求文件或过去的审美签收。

## 目的与信息层级

面向手机的神经纤维追踪教学原型，用合成三维几何演示观察、连线、撤回、评分和档案进展。桌面评审工作区有三个区域：左侧“从设计到上线”解释固定流程并提供版本回看；中间是实时交互原型；右侧是实际交互状态。版本回看属于项目评审工具，不进入游戏 HUD，也不单独占一列。

本轮将版本控件作为现有流程列表中的折叠条目，复用宽度、53px 最小条目高度、圆角、内边距及 7px 列表间距。版本选择、固定链接和并排对照保留。窄屏用“从设计到上线”统一折叠入口承载同一左栏，只有一个选择器，不复制状态；游戏画面按剩余高度缩放。

## 游戏与状态

主导航为研究、文明、群星；个人中心、信箱、补给、设置为系统功能；回声档案／任务手册是独立任务入口。研究场景保留左上样本信息、右上提示／调节、左下坐标标识、选择与连线反馈、连接／撤回等操作。图像提供美术层，端点、按钮、文字、评分和状态由真实组件和几何控制。

当前八份几何中，六份有教学答案的训练与两份开放观察委托分别处理。边界截断末端可检查、不能用作连接。投影相交不自动表示三维连通。模拟视觉、训练得分和游戏积分都不能直接当作真实科研贡献。

## 保存和边界

访客试玩用浏览器本机存档；正式账号由受限服务端验证。历史回看隔离版本进度并阻断正式写操作，榜单使用原交付归档中的公开聚合快照。私人信件和授权卡不进入公共素材或测试截图。真实科研数据、专家标注、实物履约和平台 OAuth 审核均不能从原型界面推定已完成。

本轮不修改游戏几何、积分、认证、服务端接口行为或历史游戏字节。具体回看外壳在 `review/shell.js`／`shell.css`，当前几何来源为根 `scene3d.js`。
