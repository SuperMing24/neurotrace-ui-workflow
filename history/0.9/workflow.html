01 / BRIEF明确结构与验收标准

先把界面拆成主页面、次级页面和状态，不要把“更精致一点”当成可执行需求。这里明确：研究是默认游戏页；底部导航只有研究、文明、群星；游戏内有任务、档案、帮助、视图；外部补给和设置在最上方；主要操作为撤回、连接、末端、跳过。

输入
截图 + 功能描述 + 用户评审
交付
DESIGN_BRIEF.md + 页面导航表 + QA 条件

02 / IMAGEGEN用 ChatGPT 生图进行艺术指导

先生成完整页面的高保真概念，锁定材质、光效、色彩和信息密度；同系列页面沿用同一风格锚点。该阶段产物应当被标为“视觉参考”，不是最终可交互界面。

尽量另外生成“无文字、无按钮、无节点标记”的干净场景背景，比直接从完整 UI 截取会更容易复用。本案例验证了从现有概念图拆图的方案，但还保留部分烧录在位图里的神经连线，不能直接作为正式科研数据。

03 / ASSETS裁切、蒙版和 WebP 资源

把概念图中可复用的背景、头像、徽章和档案缩略图提取出来，记录源文件、裁切坐标和蒙版形式。Pillow 提供 Crop、Alpha、GaussianBlur 和 WebP 输出；在项目中用 manifest.json 保存来源。

python -m pip install pillow numpy
python tools/build_assets.py
# 输出 assets/*.webp 与 assets/manifest.json
设计边界
美术图像 ≠ 实际节点数据；交互位置仍由 DOM / Canvas / 3D 引擎控制

04 / WEB PROTOTYPE将视觉素材合成可操作网页

图像作为美术资产进入页面，使用 <img>、CSS background 和透明叠层；按钮、文字、计分、进度条、页面切换必须是可操作元素。本案例无数据库也能展示真实的页面状态变化。

# 进入工程根目录
python -m http.server 8000
# 然后用浏览器打开 http://127.0.0.1:8000

动态网页有不同层次：CSS 动画是视觉动效，JavaScript 是浏览器状态交互，WebSocket / API / 数据库用于真实多人数据与服务端功能。本次只需要前两层，**不必为了发光按钮和状态更新而引入后端**。

05 / PLAYWRIGHT怎样自动看效果、发现遮挡？

Playwright 是浏览器自动化测试工具。它启动 Chromium，像真实用户一样打开网页、点击按钮、读取状态、截取截图。它并不设计图片，也不判断“是否高级”，而是对已确定的设计做工程一致性检查。

python -m pip install playwright
python -m playwright install chromium
python tests/verify_v09.py --base-url http://127.0.0.1:8000

测试文件会检查底部导航和操作栏是否相互遮挡、图片是否成功加载、端点选择后按钮状态是否改变、连线是否增加任务进度、档案与排行榜能否正常切换，以及手机教程抽屉能否打开。

from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch()
    page = browser.new_page(viewport={"width": 390, "height": 844})
    page.goto("http://127.0.0.1:8000")
    page.locator("#nodeB").click()
    assert page.locator("#connect").is_enabled()
    page.locator("#phone").screenshot(path="game.png", animations="disabled")
    browser.close()

为什么截图时设置 animations="disabled"？因为动态闪烁和粒子位置每帧都变化，不固定画面会造成大量无意义的视觉差异。正式审核时应同时保留真实动画预览。Playwright 官方截图文档 ↗

06 / VERCEL部署成每个合作者都能访问的网页

本项目是纯静态前端，Vercel 保存网页和 WebP 资源并提供 HTTPS 域名，无需数据库。在具备授权的连接下，可通过 Vercel API 发布；也可本机安装 CLI 后发布，或长期绑定 GitHub 仓库自动生成 Preview 链接。

# 可选：在已登录 Vercel CLI 的电脑中
npm i -g vercel
vercel deploy            # 获取审稿 Preview URL
vercel deploy --prod     # 审核通过后生产发布
Preview 的访问保护取决于项目配置，生产网址也需验证权限。用公开链接共享前，先确认素材与数据已获授权。本项目展示的神经影像及榜单内容均为示例。
